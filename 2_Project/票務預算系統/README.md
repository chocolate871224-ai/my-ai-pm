# 票務預算系統（Ticket & Seat）

高雄巨蛋等場館的票區規劃、預算、開賣後銷售與鎖位管理。Google 試算表綁定的 Apps Script 網頁，座位＝試算表格子的顏色。

## 資料夾

```
src/Index.html    前端（唯一的來源，含示範資料，開頭是 <title>）
src/Code.gs       後端
tools/build.py    從 src 產出 dist 的所有檔案，並檢查語法
tools/copy-page.template.html   程式碼複製頁的樣板
tests/test_sales.cjs            後端銷售功能測試（模擬試算表）
dist/             產出物，不要手改
  gas/Index.html  → 貼進 Apps Script（已拿掉示範資料）
  gas/程式碼.gs   → 貼進 Apps Script
  gas/appsscript.json → 專案設定（從 src/appsscript.json 複製）
  copy-page.html  → 發布到程式碼複製頁
```

## 改程式的流程

1. 改 `src/` 裡的檔案（設計上的改動先出示意圖，確認後才改）
2. 建置並測試：
   ```bash
   python3 -I tools/build.py
   node tests/test_sales.cjs src/Code.gs
   ```
3. 需要時發布程式碼複製頁（dist/copy-page.html）
4. 推之前先把線上程式抓回暫存資料夾比對，確認 Apps Script 上沒有在別處改過的程式（11/14 的第 13 版就是直接在線上改的）：
   ```bash
   cd .pull && ../node_modules/.bin/clasp pull && cd ..
   ```
5. 上線（clasp 已登入）：
   ```bash
   npm run push                       # 建置＋測試＋推上 Apps Script
   npm run deploy -- "1117 說明"      # 正式網址換成新版本（網址不變）
   ```
   沒有 clasp 時：把 `dist/gas/` 的兩個檔案貼進 Apps Script → 存檔 →「管理部署作業」› 鉛筆 › 新版本 › 部署

## 試算表分頁

| 分頁 | 角色 |
|------|------|
| 票價座位 | 規劃底稿。規劃頁面讀寫這裡，銷售功能不會動它 |
| 票券銷售及鎖位 | 實際銷售。已售／策略鎖位／貴賓保留直接改格子底色；圖例「該區票房」右邊三欄寫各票價張數 |
| 銷售狀態 | 每個已售／鎖位／保留座位一列，第 14 欄「原本顏色」用來退票時改回 |
| 每日售出 | 每天、每個票價的新售、退票 |
| 鎖位通知 | 要通知售票窗口的鎖位紀錄（待通知／已通知） |
| 座位註記、規劃紀錄 | 不售註記、每次儲存的紀錄 |
| 預算明細、預算評估 | 預算頁面讀取 |
