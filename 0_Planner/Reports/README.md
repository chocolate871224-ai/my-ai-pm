# Reports — 階段性自我盤點與評估

the-assistant 的分析輸出層。存放**階段性的效率／餘裕／忙碌程度盤點**——不是每日/每週的例行操作（那在週檔），
而是結構轉折點（季末、半年、年中、換工作、專案結束等）的一次深度評估。

## 與 Planner 其他層的分工

| 層 | 性質 | 產出 |
|----|------|------|
| Weeks / Monthly / goals | 規劃與執行（時間軸） | 任務、目標、進度 |
| Collections | 主題軸任務清單 | 具名主題 |
| **Reports（本資料夾）** | **分析與反思** | 盤點報告、餘裕判斷 |

## 產生方式

由 `review-stage` skill 產出。三個步驟：**目標盤點 → 成果盤點 → 過程分析**
（過程分析含忙碌曲線、餘裕帳、負載三分類、突發產生器辨識、質>量詮釋）。

叫 the-assistant「盤點我這階段的效率/餘裕」「下半年會不會比較輕鬆」即可觸發。

## 命名

`YYYY-MM-DD_<主題>.md` — 一份報告一個檔，日期為完成盤點日。
